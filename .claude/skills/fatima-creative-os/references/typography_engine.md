# typography_engine

Un sistema tipográfico profesional que se **adapta al proyecto** — no una fuente
por defecto para todo. La tipografía es voz: cambia el tono antes que el
contenido.

## Qué controla

- **Elección de fuentes** — según registro (serif display para luxury/editorial,
  grotescas para moderno/tech, humanistas para cercano, monoespaciadas para
  cyber/técnico, manuscritas para handmade).
- **Parejas tipográficas** — normalmente una display + una de texto. Combina por
  contraste (una con carácter, otra neutra), nunca dos protagonistas.
- **Jerarquía** — display / título / subtítulo / cuerpo / caption. Cada nivel se
  distingue por tamaño **y** peso **y** color, no por uno solo.
- **Tamaño, peso, tracking, leading** — el tracking se abre en mayúsculas y
  titulares luxury, se cierra en display grandes; el leading respira en cuerpo,
  se ajusta en titulares.
- **Alineación** — a bandera izquierda por defecto; centrado solo con intención
  (elegancia, simetría); justificado solo con buen control de ríos.
- **Contraste y composición** — la tipografía compone: puede ser el elemento
  gráfico principal.

## Tipografía expresiva y cinética

Cuando el texto **es** el protagonista:

- **Expresiva** — la forma refuerza el significado (una palabra que se estira,
  se rompe, se ilumina). Úsala con moderación y coherencia.
- **Cinética** — texto en movimiento (ver `motion_engine`): word/character
  reveal, type-on, split, stretch, kinetic typography. Clave en social y anuncios.
- **Texto 3D / extrusión** — para impacto y producto (ver `three_d_engine`).

## Reglas prácticas

- Máximo 2 familias por pieza (3 si una es solo para datos/etiquetas).
- La legibilidad manda: en móvil, cuerpo suficientemente grande y contraste alto.
- El sistema tipográfico se fija en el brief y se documenta para la marca
  (`brand_engine`), para que toda la campaña hable con la misma voz.
- No repitas siempre la misma pareja: cada proyecto pide su propia voz.
