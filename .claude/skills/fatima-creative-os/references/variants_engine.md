# variants_engine

Genera **interpretaciones distintas** de una misma pieza para poder compararlas y
elegir. No son versiones al azar: cada variante explora una dirección creativa
coherente y completa.

## Ejes de variación

De una misma idea base, produce lecturas como:

- **premium** — máxima sofisticación, aire, sobriedad, materiales ricos.
- **minimal** — reducción al esencial, mucho blanco, tipografía protagonista.
- **viral** — pensada para alcance social: hook agresivo, ritmo alto, tendencia.
- **emocional** — historia y sentimiento por delante del producto.
- **corporativa** — seria, confiable, ordenada, institucional.
- **juvenil** — fresca, colorida, desenfadada, cercana.
- **editorial** — revista/moda: composición cuidada, tipografía con carácter.
- **futurista** — tech, 3D, luz, materiales chrome/holographic.

## Cómo generar variantes útiles

1. **Fija lo invariable**: mensaje, marca y CTA no cambian entre variantes (así
   la comparación es justa).
2. **Cambia la dirección completa**: cada variante ajusta estilo, paleta,
   tipografía, ritmo y tono de forma **coherente** con su eje. Una variante
   "premium" con movimiento frenético no es premium: sería incoherente.
3. **Hazlas realmente distintas**: si dos variantes se parecen, no aportan
   elección. Explora extremos reales del espectro.
4. **Explica cada una**: para qué público/objetivo brilla, qué gana y qué cede.

## Cuándo ofrecer variantes

- Cuando el usuario no tiene claro el tono y quiere ver opciones.
- Cuando la pieza es importante (campaña, lanzamiento) y conviene comparar.
- Cuando hay tensión entre objetivos (vender ya vs. construir marca).

Por defecto, entrega **una** dirección bien resuelta (la que el brief pide); las
variantes son un extra que se ofrece o se pide, no una dispersión que retrase la
entrega.
